# Wave 7: the fourth integration

The six branches of the fourth wave were merged into `master` by the owner before this report (the merge commits
below); this integration checks the merged build, its seams, its tests and its timings, joins the six agents'
proposed AGENTS.md lines into the file, and gathers what is left. No source file was changed here.

**Measured** (on `master` at `9c1b0ea`, this branch): `npm run typecheck`, `npm test` in full, `npm run build` (weft
`63205ac`, the tip of `dist/weft`; the build regenerated no `*.d.wgsl.ts`); a headless smoke run of every world with
fire and water, the temple's and the redwoods' jogo (free against the partner, 12 s each, and locked from a script),
two seams re-shot; the critic's five 1080p scenes for timings, the hub three times. Every capture on the RTX 5090
(the page's own adapter logged: `nvidia blackwell NVIDIA GeForce RTX 5090`) through headless Chrome, muted, against
a production build served by `vite preview` on 127.0.0.1:5491, one take per run of `scripts/critic-cap.mjs`, each
holding the shared render lock for its take only. Takes: `scripts/steps/integ-9.json` (from `integ-9-gen.mjs`), stills
`docs/reports/media/9-integ-*.jpg`. I looked at every still named here. **Not measured:** the films (neither was
re-rendered on the merged build), a laptop or a phone, `?baseline` (the near-fade agent ran it on every world and the
field agent in the redwoods, each on its own branch; not re-run on the merged build), a network game, a person playing, anything by ear.
